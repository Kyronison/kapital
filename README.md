# Капитал

Браузерная многопользовательская игра о финансовой грамотности: игроки получают профессию,
вкладывают свободные деньги в активы и стараются, чтобы пассивный доход покрыл расходы.

## Структура

| Пакет | Что внутри |
| --- | --- |
| `packages/content` | Профессии, оба круга поля, колоды «Шанс», «Проект», «Новости рынка», «Соблазн», мечты и инвестиции «Свободного пути», правила |
| `packages/engine` | Движок правил: `createGame`, `applyAction`, финансовые расчёты, бот |
| `packages/sim` | Симуляция баланса Монте-Карло на настоящем движке |
| `packages/server` | Игровой сервер на Colyseus: столы по ссылке, таймер хода, боты, переподключение |
| `packages/web` | Браузерный клиент на React + Vite: вход, лобби со ссылкой, поле, финансовый отчёт, журнал. Графика — в `public/art` и `src/art`, см. `packages/web/ART.md` |

Движок — чистые функции без сети и базы: `applyAction(content, state, action)` возвращает новое
состояние и список событий или ошибку. Случайность идёт только из ГПСЧ, состояние которого
хранится в `GameState`, поэтому партию можно воспроизвести по seed и журналу действий.
Сервер будет вызывать тот же движок и рассылать состояние клиентам.

## Команды

```sh
pnpm install
pnpm test          # тесты правил
pnpm typecheck
pnpm sim           # таблица баланса по профессиям (2000 партий)
pnpm sim:check     # то же на 400 партиях; падает, если баланс вне коридора
pnpm sim --mode quick --games 400 --check   # то же для быстрого режима
pnpm sim:levels     # проходимость уровней «Тренировки» ботом; с --check падает вне коридора сложности
pnpm start         # игровой сервер на ws://localhost:2567 (порт — переменная PORT); то же: pnpm run server
                  # не «pnpm server»: это встроенная команда pnpm, она ничего не запустит
pnpm web           # клиент на http://localhost:5173, сервер ищет на том же хосте, порт 2567
pnpm build:web     # статическая сборка клиента; адрес сервера — VITE_SERVER_URL
```

## Протокол сервера

Клиент создаёт стол `client.create('kapital', { name })` и делится ссылкой с `roomId`;
остальные входят через `client.joinById(roomId, { name })`. Можно передать `professionId`
и `dreamId`, иначе их выберет сервер при старте.

| Сообщение клиента | Что делает |
| --- | --- |
| `add_bot` | Создатель стола добавляет бота |
| `start` | Создатель стола начинает партию (от 2 мест), стол закрывается для новых игроков |
| `action` | Действие движка без `playerId`, например `{ type: 'ROLL' }`: игрок определяется по соединению |

Сервер рассылает `view` (места и партия без колод и состояния ГПСЧ, плюс `turnDeadline`),
`events` (события движка) и `error` конкретному игроку. На ход даётся 30 секунд, потом его
доигрывает бот. Отключившийся игрок может вернуться в течение 60 секунд, пока за него ходит бот.

## Как выиграть

1. **«Круг забот».** Пассивный доход должен покрыть все расходы. Тогда в конце хода игрок
   переходит на «Свободный путь» со стартовым доходом = пассивный доход × 10.
2. **«Свободный путь».** Кредитов нет, доли инвестиций покупаются за наличные. Победа:
   купить свою мечту (цена — 6–12 стартовых доходов) или удвоить доход.

`sim:check` запускается в CI и проверяет для каждой профессии: медиана ходов до выхода из
«Круга забот» 20–30, доля партий без выхода не больше 5%, медиана ходов на «Свободном пути»
от выхода до победы 6–14.
