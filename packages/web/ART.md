# Графика

Набор нарисован под эту игру в ChatGPT по промпту из проекта: палитра, иконки, портреты профессий, мечты, рубашки колод, иллюстрации карт, центр поля, фишки, кубики, фоны экранов и CSS-анимации. Отсылок к другим играм и реальным брендам нет, текста в растровых картинках нет.

| Где | Что |
| --- | --- |
| `src/art/icons` | 79 линейных SVG 24×24 на `currentColor`: клетки, активы, эмблемы акций, интерфейс. Вставляются в разметку через `Icon` из `src/art.tsx` |
| `src/art/brand`, `src/art/tokens`, `src/art/dice` | Логотип, фишка (цвет через `currentColor`), грани кубика |
| `public/art` | Растровые картинки в WebP: `professions`, `dreams`, `deals`, `decks`, `board`, `screens`, а также грани кубика для CSS |
| `src/motion.css` | Анимации набора: бросок кубика, шаг фишки, вылет и переворот карты, всплывающие суммы, пульс клетки, таймер хода, вспышка выхода, конфетти, встряска. Учитывают `prefers-reduced-motion` |

Исходные PNG из архива были 23 МБ. При переносе они пережаты в WebP и уменьшены до размера показа, вместе это около 1,5 МБ.

Палитра: изумруд `#0F5C4D`, золото `#E3A72F`, крем `#F6F1E7`, графит `#1C2321`, коралл `#E0604A`, небесный `#4A90C2`, сливовый `#7A4E8C`.
